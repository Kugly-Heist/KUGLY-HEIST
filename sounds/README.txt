CS2 sounds for CHICKEN HEIST
============================
The game first looks for the MP3 files below in this folder. If a file is
missing it falls back to the same sound hosted on myinstants.com, and if that
fails too it uses the old synth beep.

Save each sound from myinstants.com (the "Download" button) under this exact name:

  cs-2-play-button.mp3                              PLAY button
  counter-strike-jingle-cs-radio-ok-lets-go.mp3     run start (random 1 of 2)
  passos-counter-strike.mp3                         run start (random 1 of 2)
  ez4ence-cs2.mp3                                   CT wins / you get caught (random 1 of 2)
  easy-peasy-lemon-squeezy-csgo.mp3                 CT wins / you get caught (random 1 of 2)
  cs2.mp3                                           buying an upgrade in the shop
  cs-go-headshot-sound.mp3                          hitting an obstacle (played at 50 % volume)

Volume follows the SFX slider / toggle in the game menu.
